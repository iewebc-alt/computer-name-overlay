# Security

The latest release is the supported version; earlier releases receive fixes through an update to the latest version.

Use GitHub's private vulnerability reporting facility in this repository's Security tab if enabled. If unavailable, open an issue asking for a private reporting channel without publishing exploit details or personal information. The repository owner should enable private reporting before launch.

The app is a normal user process with an optional per-user startup entry. It is not a security boundary and does not bypass organizational application control. A signature does not mean an administrator has approved a binary for your environment.
