# Contributing

Open an issue describing a concrete bug or proposed behavior, then submit a focused pull request. Remove personal hostnames, domain names and local paths from examples and screenshots.

Run `build.ps1` and `test.ps1` on Windows. For UI changes, check light/dark backgrounds, click-through, keyboard focus, monitor changes and quitting from the tray. Describe the Windows version and display scaling in the PR. Contributions are provided under the project's MIT license.

Changes to build scripts, workflows and signing documentation need explicit review. Do not add credentials, binary dependencies, auto-updaters or hidden startup behavior. Do not change execution-policy or application-control settings.
