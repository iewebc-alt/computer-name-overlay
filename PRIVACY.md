# Privacy policy

Computer Name Overlay reads the local computer name and monitor working areas to draw the overlay. It does not send these values anywhere. It has no telemetry, analytics, advertising, network client, update check or crash-upload feature.

Optional startup and display preferences are stored in the current user's Windows registry, as described in the README. A developer-invoked self-test writes a report and a preview using a fictional computer name to the path specified by the developer. Failures during that test may include local paths in the local error report; review reports before posting them.

The displayed hostname is visible to people viewing the screen and may appear in screenshots, recordings or screen shares. Exit the application when it should not be shown.

The application uses Windows/.NET system libraries, not third-party runtime services. GitHub and SignPath are development/distribution services, not services contacted by the application. Visiting their sites is subject to their own privacy policies.
