# Computer Name Overlay

Утилита показывает имя компьютера справа внизу поверх обычных окон, сохраняя личные обои пользователя. Полупрозрачный текст пропускает клики и не забирает фокус. Windows 10/11, стандартный .NET Framework 4.x, без установки и прав администратора.

Скачайте ZIP из Releases, распакуйте в постоянную папку и запустите `ComputerNameOverlay.exe`. В меню значка трея: **Show on all monitors** — все мониторы; **Start when I sign in to Windows** — автозапуск; **Exit** — выход. Автозапуск по умолчанию выключен.

Подпись пока не подключена; проект готовится к заявке SignPath Foundation. Первые сборки явно помечены unsigned. Подпись не отменяет запрет запуска в домене: администратор должен разрешить приложение.

Защищённые экраны Windows, эксклюзивный полноэкранный режим и другие окна поверх всех могут закрывать надпись. Имя берётся из Windows, а не задаётся вручную. Нет сети, телеметрии и автообновлений.

Для удаления выключите автозапуск в меню, завершите программу и удалите её папку. Настройка мониторов остаётся в `HKCU\Software\ComputerNameOverlay`; её можно удалить вручную. Запись автозапуска — только значение `ComputerNameOverlay` в `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`.

Сборка на разрешённом ПК разработчика: `build.ps1`, проверка: `test.ps1`, архив: `package.ps1`. Клиентам эти скрипты не нужны. Лицензия MIT; подробности в основном README и Code signing policy.
