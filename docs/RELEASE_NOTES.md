# Computer Name Overlay 0.1.0

Initial version: translucent, click-through computer-name text, primary/all-monitor modes, tray exit and optional per-user startup. Leaves the user's wallpaper unchanged. Supports Windows 10/11 with the system .NET Framework runtime.

Exclusive fullscreen and secure desktops may cover the text. Application-control approval remains the administrator's responsibility. See the repository README for installation and removal.

## Code signing policy

See `CODE_SIGNING.md` in the package and the linked repository policy for signing status, approval roles and privacy. The release workflow appends the actual signing state and source commit below.
